## 第一部分：总体评估

当前六篇论文一致表明：尽管多模态大模型（MLLM）在视觉识别类基准上接近饱和 — 单图像物体感知准确率可达 80–90%，但在深层视觉理解上存在系统性缺陷。具体表现为：(1) 透视几何理解薄弱，最佳模型在 MMPerspective 上整体准确率仅约 57% [A]；(2) 跨场景推理能力极差，GPT-4o 在 Common-O Bench 上仅 35%，复杂场景不足 1% [B]；(3) 认知层面存在"Middle Score Anomaly"，最佳模型在 VisFactor 上仅 54.0% [C]；(4) CLIP 视觉编码器对方向、计数、视角等基础模式存在系统性盲区 [D]；(5) 即使 GPT-4V 在 BLINK 上也仅 51.26%，比人类低 44% [E]；(6) 低层视觉任务（如判断两圆是否相交）中 VLM 平均仅 58.07% [F]。共识是 MLLM 擅长高层语义识别，但缺乏类似人类的底层视觉感知与几何推理能力。主要局限包括：多数基准尚未饱和但测试规模有限，合成图像与真实场景的域偏移问题待解决，模型架构改进方向尚不明确。

## 第二部分：逐条结论

- 结论 1：MLLM 在透视几何理解上存在严重缺陷，43 个模型在 MMPerspective 上的最高总体准确率仅为 57.2%（Gemini-2-flash CoT），远未达到人类水平。
  出处：[A] §3.2::T1 / [A] §3.2::¶1

- 结论 2：MLLM 在跨场景推理中表现极差 — 单图物体识别准确率高（单图 >80%），但回答"两图共有物体"时 GPT-4o 仅 35%，复杂场景（8–16 物体）最高不足 1%。
  出处：[B] §4.1::¶1; §4.1::F3 / [B] §4.2::T2

- 结论 3：MLLM 的视觉认知停留在概念识别层面而非真实视觉处理 — 在 VisFactor 的记忆测试中，模型依赖可语义化的概念而非低层视觉模式完成匹配。
  出处：[C] §3.4::¶6; §3.4::T3

- 结论 4：MLLM 普遍存在"中等分数异常"— 在人类可完美解决的任务（如判断两幅图像是否描绘同一物体）上，模型却仅获得 30–60% 的中间准确率，表明其缺乏真正的视觉推理能力。
  出处：[C] §3.2::¶3

- 结论 5：CLIP 视觉编码器是 MLLM 视觉缺陷的关键瓶颈 — CLIP 在方向、计数、视角等 7/9 种基础视觉模式上存在系统性失效，且这些缺陷显著传递至下游 MLLM（Pearson r > 0.7）。
  出处：[D] §3.1::¶末; §3.2::T1 / [D] §3.3::¶2

- 结论 6：即使最先进的 MLLM（如 GPT-4V）在 BLINK 的 14 项基础视觉感知任务上仅得 51.26%，比人类（95.70%）低 44.44 个百分点，仅比随机猜测高 13.17%。
  出处：[E] Abstract::¶1 / [E] §1::¶末

- 结论 7：VLM 在极简单的低层视觉任务（判断两圆是否相交、识别被圈字母、计数重叠形状）上平均准确率仅 58.07%，其中最佳模型 Sonnet-3.5 也仅 77.84%，远低于人类预期 100%。
  出处：[F] §4::T1 / [F] Abstract::¶1

- 结论 8：线性探测实验表明，VLM 的视觉编码器已包含足以解决低层视觉任务的丰富信息（准确率 ≥99.47%），瓶颈在于语言模型无法将视觉信息解码为正确答案。
  出处：[F] §6::¶1
