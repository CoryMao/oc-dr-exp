# ORIGINAL_REPORT

## 第一部分：总体评估

基于六篇论文，当前证据一致表明：在未加管控的情况下，递归式合成数据训练会导致 LLM 性能退化（model collapse），但退化的形式和严重程度取决于数据混合比例、训练策略、模型模态和指令格式等条件。[A] 将知识退化刻画为三阶段过程，"流畅但错误"的中间阶段构成最危险的失效模式。[B] 和 [D] 分别从理论与实证角度证明，数据累积和弱标注注入可以避免 collapse 并收敛到最优。[E] 发出最强警告：即使仅 1% 的合成数据也可破坏 scaling law。然而 [C] 发现多模态场景下 collapse 表现与单模态迥异，VLM 方差反而上升。[F] 提出验证/筛选范式，证明即使不完美的验证器也能防止 collapse。主要局限在于多数实验规模较小（1B 级模型），在真实 web-scale 条件和大规模多智能体交互下的长期动态仍缺乏系统刻画。

## 第二部分：逐条结论

- 结论 1：递归合成训练导致三阶段知识退化——Stage A 知识保持、Stage B "自信但错"的知识崩溃、Stage C 指令遵循崩溃，其中 Stage B 对下游应用威胁最大。
  出处：[A] §3::¶1; §3::¶2; §3::F2

- 结论 2：累积合成数据到真实数据中可避免 model collapse，而逐代替换数据则导致测试误差持续上升；这一结论在 Transformer 语言模型、扩散分子构象模型和 VAE 图像模型上一致成立。
  出处：[D] §2.1::¶1; §2.1::¶2; §3::¶1

- 结论 3：即使合成数据占总训练数据仅 1%，也可能导致 strong model collapse，使得增大训练集不再提升性能，从根本上破坏神经 scaling law。
  出处：[E] §1.1::¶3; §3.1::¶1

- 结论 4：基于 boosting 启发的理论框架证明，只要每轮迭代中至少 β>0 比例的外部标注正确，迭代训练可收敛至最优性能；在 GSM8K 和 MBPP 上 boosting 策略显著优于不筛选或仅筛选的基线。
  出处：[B] §1::¶5; §6::Theorem5; §7.1::¶4; §7.1::T1

- 结论 5：对合成数据进行验证筛选可以防止 model collapse——理论证明存在 sharp phase transition，即使不完美的验证器也能使下游模型超越生成器的原始性能。
  出处：[F] §4.3::¶1; §4.3::Theorem4.2; §6.1::¶1

- 结论 6：多模态场景（VLM+扩散模型）下的 collapse 与单模态 LLM 不同：VLM 图像描述方差上升而非下降、词汇量扩大、对齐先改善后降低；联合微调会加速共退化。
  出处：[C] §4.2::¶3; §4.2::¶4; §4.3::¶1; §4.8::¶2

- 结论 7：增加解码预算（如扩散模型的去噪步数）和模型多样性（架构或超参数层面）可有效缓解多模态系统中的 model collapse。
  出处：[C] §4.5::¶1; §4.5::F9; §4.6::T1
